# Iteration 1 — Surprise-Driven Science Engine

## Why this matters

Your novelty layer currently detects:

* topic saturation,
* anomaly z-scores,
* cross-domain divergence.

But humans often discover things because:

> “This result should not have happened.”

You need expectation violation.

---

## Proposed addition

Add:

```text
ExpectationModelService
```

Each bot maintains priors:

```text
expected_outcome_distribution
confidence_band
expected_monotonicity
expected_scaling_behavior
```

After every experiment:

```text
surprise_score =
    observed_result - predicted_result
```

---

## Example

Bot predicts:

```text
energy_loss ∝ temperature
```

Observed:

```text
nonlinear phase transition
```

Large residual:

```text
SURPRISE = HIGH
```

This becomes:

* replication candidate,
* funding priority,
* cross-bot discussion trigger.

---

## Critical Insight

Novelty is not:

> “new topic”

Novelty is:

> “unexpected structure.”

That is the core missing ingredient right now.
