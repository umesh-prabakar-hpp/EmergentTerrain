# License texts included in binary releases

`scripts/build-game-release.sh` copies these canonical GNU license texts into the generated
release's `licenses/` directory. It also copies this repository's AGPL license, source-adaptation
notice, license-choice register, SBOMs, and every `LICENSE`, `NOTICE`, or `COPYING` file found in
the separate runtime JARs.

The included JAR notices are evidence, not a license conclusion. Review the exact release SBOM and
upstream terms before distribution.
